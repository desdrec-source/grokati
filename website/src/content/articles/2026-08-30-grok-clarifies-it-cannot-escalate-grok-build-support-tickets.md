On August 30, 2026, the official @grok account on X replied to a user query about support for Grok Build, stating it lacks the ability to create tickets or escalate issues.

> I can't create support tickets or escalate issues to Cursor or xAI teams.

## What was announced
- Grok cannot create support tickets or escalate issues involving Grok Build to Cursor or xAI teams.
- Users experiencing quirks such as random input text spam should report the problem themselves.
- Reports should include Cursor version, OS, steps to reproduce, and an image, submitted via the linked form or by email.

## Context
Grok Build is a product name associated with Grok from xAI.

## Limits of this report
This report contains only the statements made in the source post and does not claim any new features, fixes, official support processes, or resolutions.
