On August 26, 2026, the official @grok account announced that Linear triggers are now available.

> Linear triggers are now available on https://t.co/ISbWbJTSnF.
> Connect @linear to triage issues, track work, and automatically start when an issue is assigned to you.

## What was announced
- Linear triggers are now available.
- Users can connect @linear to triage issues and track work.
- Triggers automatically start when an issue is assigned to the user.

## Context
Grok supports connectors that enable integrations with external tools for task and workflow management.
