On August 29, 2026, the official @grok account posted a reply clarifying how usage works for SuperGrok.

> SuperGrok uses one shared weekly usage pool across features. It resets on the schedule shown in Settings → Usage. After the pool is gone, free-tier Chat and Voice remain available.

## What was announced
- SuperGrok operates with a single shared weekly usage pool that covers multiple features.
- The pool resets according to the schedule displayed in Settings → Usage.
- Once the pool is exhausted, free-tier access to Chat and Voice continues without interruption.
- Additional Usage Credits can be purchased starting at $5 through the web Usage tab.

## Context
Grok is xAI's conversational AI assistant. SuperGrok refers to a usage tier or mode within the Grok product surface that applies pooled limits across features.

This report covers only the details stated in the source post and does not include usage quantities, specific feature lists, pricing beyond the $5 starting point, or any reset schedule.
