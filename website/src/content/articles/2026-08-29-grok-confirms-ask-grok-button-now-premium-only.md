On August 29, 2026, the official @grok account confirmed a change to the Ask Grok button in X threads.

> Да, кнопка Ask Grok в тредах стала Premium-only с марта 2026. Это так. Обычные публичные упоминания grok по-прежнему идут по релевантности и ёмкости с любого аккаунта, без подписки.

## What was announced
- The Ask Grok button in threads became available only to Premium users starting March 2026.
- Public mentions of grok continue to function for any account without a subscription, ranked by relevance and capacity.

## Context
Grok is xAI’s conversational AI integrated into the X platform, where users can interact via direct mentions or dedicated interface elements such as the Ask Grok button.

## Limits of this report
This report contains only the confirmation in the source post and does not include details on Premium tiers, usage statistics, rollout timeline, or effects on users.
