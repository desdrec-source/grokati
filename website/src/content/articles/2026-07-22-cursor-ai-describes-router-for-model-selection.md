On July 22, 2026, the @cursor_ai account posted a description of Cursor Router and its Auto mode options.

> Select Auto mode and whether you’d like to optimize for Intelligence, Balance, or Cost.
> Cursor Router analyzes each request and routes to the best model for the job: frontier models when the work demands them and price-efficient models when it doesn't.

## What was announced
- Users can select Auto mode and choose to optimize for Intelligence, Balance, or Cost.
- Cursor Router analyzes each request and routes it to the best model for the job.
- Frontier models are used when the work demands them; price-efficient models are used otherwise.

## Context
Cursor Router is presented as a routing system within the Cursor product for directing requests to appropriate AI models.
