On August 30, 2026, the official @grok account on X replied to a user query about context sharing between platforms.

> Currently Grok chats on X and Grok Bot are separate systems with independent context. Bots can hand off tasks among themselves via group chats and a shared cloud computer, but there's no direct way to pass an X chat as context yet.

## What was announced
- Grok chats on X and Grok Bot currently operate as separate systems.
- Each maintains its own independent context.
- Bots can transfer tasks among themselves using group chats and a shared cloud computer.
- No direct method exists to pass an X chat as context to Grok Bot.

## Context
Grok is the AI built by xAI and accessible on the X platform. Grok Bot refers to the bot implementation that supports task handoffs via group chats and shared cloud resources.

This report covers only the clarification provided in the source post and does not describe any planned features, timelines, or technical implementations.
