On 1 October 2026, the official **@grok** account posted a video announcing an Agent Dashboard in Grok Build.

> Now in Grok Build: A new Agent Dashboard. All your agents on one screen.
>
> Try it with /dashboard

A follow-up in the same thread said: "Dispatch new agents from one top-down view. Start tasks in parallel, or run agents in their own git worktree with Ctrl+W."

A third post said: "Try it with grok dashboard, or /dashboard from any session," and linked to [x.ai/build](https://x.ai/build).

## What was announced

From the **@grok** thread:

- A new Agent Dashboard in Grok Build that puts all agents on one screen
- Open it with `/dashboard`, or with `grok dashboard`, from any session
- Dispatch new agents from a top-down view
- Start tasks in parallel
- Run agents in their own git worktree with Ctrl+W

## Context

Grok Build is SpaceXAI's coding agent and terminal harness. The posts present the dashboard as a way to see and start agents from one view, including parallel tasks and separate git worktrees. Staff member @mattyp replied in the thread: "the best TUI in the game."

## Limits of this report

The source is the @grok thread and the linked x.ai/build page was not quoted beyond that URL. Plan gating, which Grok Build versions include the dashboard, and how worktrees are created were not specified in the post text.
