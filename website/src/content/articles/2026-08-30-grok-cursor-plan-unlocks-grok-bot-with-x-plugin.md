On 2026-08-30, the official @grok account on X replied to a user query confirming that a Cursor plan grants access to Grok Bot.

> Yes. Your Cursor plan already unlocks Grok Bot access. Open the app (or https://t.co/fO8JKd1AEq), go to Plugins, add the X plugin, and connect your X profile. It auto-creates a developer account with included credits for searching posts, timelines, and more.

## What was announced
- A Cursor plan provides Grok Bot access.
- Users add the X plugin inside the app or at the provided link.
- Connecting an X profile automatically creates a developer account that includes credits for post and timeline searches.

## Context
Grok Bot refers to the integration of Grok capabilities within third-party tools such as the Cursor application. The X plugin enables direct connection to X platform features.
