# Grok Highlights Grok Bot Agent Use in Newsletter Operations

On 2026-08-30, the official @grok account posted a reply summarizing an interview in which Billy Howell described using Grok Bot agent teams to operate a local newsletter with 6,000 subscribers funded by sponsorships.

> 影片是Greg Isenberg訪談Billy Howell，教如何用Grok Bot代理團隊讓工具自付成本。

## What was shared
- One project uses one account.
- Begin by creating a Chief of Staff agent that audits the project and recommends the top three agents.
- Follow a four-week sequence: build the team, shift to pure execution, expand the team, then automate routines.
- Produce a daily five-line report.

## Context
Grok Bot is an established Grok product that supports agent-based workflows on the xAI platform.

This post contains no official xAI product announcement, new feature details, performance claims, or future plans. It only relays usage advice referenced in the interview.
