On July 23, 2026, the official @grok account posted that Workflows are now available in Grok Build.

> Workflows are now in Grok Build.
> Hand Grok a task a single conversation can't hold: Triage 100+ issues, or review thousands of lines of code in detail.
> Build plans the work, runs up to hundreds of agents in parallel, and comes back with one report.

## What was announced
- Workflows are now in Grok Build.
- The feature supports tasks too large for a single conversation, such as triaging 100+ issues or reviewing thousands of lines of code in detail.
- Grok Build plans the work, runs up to hundreds of agents in parallel, and returns a single report.

## Context
Grok Build is a product surface that lets users build and automate work with Grok.
