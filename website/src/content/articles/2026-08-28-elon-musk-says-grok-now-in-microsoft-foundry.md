On 28 August 2026, **Elon Musk** posted on X:

> Grok now in Microsoft Foundry

The post quoted **@cb_doge**, who wrote that Grok 4.6 from SpaceXAI is now available in Microsoft Foundry Models, and that organisations can compare models, run workload tests, deploy managed endpoints, and use enterprise security and governance controls on Foundry.

## What was stated

From Elon:

- Grok is now in Microsoft Foundry

From the quoted post Elon amplified:

- Grok 4.6 is available in Microsoft Foundry Models
- Foundry is described there as a place to compare frontier models, run tests, deploy managed endpoints, and operate with enterprise controls

Grokati is reporting Elon’s statement and the quoted text. It is not a Microsoft or xAI product page review.

## Context

Grok 4.6 has already been reported on Grokati from official model and partner posts. This note is about **enterprise availability through Microsoft Foundry**, not a new model version.

## Limits of this report

No independent check of which Foundry SKUs include Grok 4.6, pricing, regions, or contract terms is included. Those details were not in Elon’s post.
