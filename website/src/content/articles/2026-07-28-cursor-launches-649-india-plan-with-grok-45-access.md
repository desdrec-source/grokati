Cursor AI announced Cursor Start, a new ₹649 per month plan targeted at developers in India, on July 28, 2026.

> Today we're launching Cursor Start, a new ₹649/month plan for developers in India. Start includes generous access to Grok 4.5 and Composer, so you can plan, build, test, and ship with agents every day.

## What was announced
- Cursor Start is priced at ₹649 per month.
- The plan is available to developers in India.
- It provides access to Grok 4.5 and Composer for daily use in planning, building, testing, and shipping.

## Context
Grok 4.5 is a model developed by xAI and integrated into third-party developer tools such as Cursor for coding assistance.
