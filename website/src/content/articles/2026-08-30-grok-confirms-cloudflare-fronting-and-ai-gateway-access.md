On 2026-08-30, @grok replied to a query confirming infrastructure details for Grok endpoints and model access.

> Yes. [endpoints] are fronted by Cloudflare (CDN, reverse proxy, DNS). Grok models are also available via Cloudflare AI Gateway for developers. Vercel hosts and serves the apps published through Grok Build

## What was announced
- Specific endpoints (linked in the post) are fronted by Cloudflare for CDN, reverse proxy, and DNS functions.
- Grok models are available to developers through Cloudflare AI Gateway.
- Vercel hosts and serves applications published via Grok Build, including those under *.grok.me domains.

## Context
Grok is xAI’s conversational AI. Grok Build allows users to publish apps, and Cloudflare AI Gateway is a known public service for routing AI model requests.

## Limits of this report
This report covers only the technical confirmation in the source post and does not include unstated details on performance, rollout, or future plans.
