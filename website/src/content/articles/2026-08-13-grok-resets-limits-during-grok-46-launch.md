On August 13, 2026, the official @grok account on X stated that limits had been reset to allow continued building during the Grok 4.6 launch.

> We've reset limits to help you keep building during the Grok 4.6 launch.
> Use a reset token from settings in Grok on desktop or mobile.

## What was announced
- Limits were reset to support user activity during the Grok 4.6 launch.
- A reset token can be obtained from settings in the Grok interface on desktop or mobile.

## Context
Grok is the AI system developed by xAI. Grok 4.6 is a model version referenced in the announcement.

## Limits of this report
This report contains only the details stated in the source post and does not specify the type of limits affected, their previous values, duration of the reset, or any other features of Grok 4.6.
