Elon Musk posted on X on August 18, 2026, recommending that users try Grok 4.6 and noting that Grok 4.7 is in development.

> Try Grok 4.6!
> Grok 4.7, which is a major upgrade, is coming soon.

## What was announced
- Musk encouraged users to try the current Grok 4.6 model.
- He stated that Grok 4.7 represents a major upgrade and will be released soon.

## Context
Grok is the AI model family developed by xAI. Grok 4.6 is the version currently referenced for user access.

## Limits of this report
This report contains only the statements in the source post and does not include any details on features, performance, release timing, or capabilities of either model version.
