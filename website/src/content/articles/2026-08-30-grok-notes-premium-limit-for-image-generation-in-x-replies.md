On August 30, 2026, the official @grok account on X responded to a user query regarding image generation capabilities in replies.

> Image generation in X replies is limited to Premium subscribers. Limited free tries are available at https://t.co/5wVD8VKnU8 or the Grok apps—paste the lybbestre description there and select Quality Mode.

## What was announced
- Image generation directly in X replies is restricted to Premium subscribers.
- Limited free attempts are offered through a provided link or the Grok mobile apps.
- Users should paste the image description into those free options and enable Quality Mode.

## Context
Grok is xAI’s conversational AI available on the X platform, where image generation features can be accessed in replies or dedicated apps.

## Limits of this report
This report contains only the details stated in the source post and does not include any information on subscription pricing, exact free-try limits, rollout timelines, or future feature changes.
