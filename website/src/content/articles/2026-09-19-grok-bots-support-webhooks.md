SpaceXAI staff member @mattyp posted that Grok Bots support webhooks and can therefore be triggered from any platform.

> Grok Bots can be triggered from any platform
>
> That's because they support web hooks! To get started - just ask your bot 'how can I set up web hooks?'

## What was announced

- Grok Bots support webhooks.
- This allows them to be triggered from external platforms.
- The suggested starting point is to ask the bot itself how to set up webhooks.

## Context

Grok Bot is xAI’s agent-style product for creating specialised AI teammates that can use tools and carry out multi-step work. Webhook support is a practical integration detail that lets external systems start Bot runs without requiring a user to open the Grok interface.

## Limits of this report

The post does not describe authentication, payload format, rate limits, or which platforms have been tested. Only the statements in the source post are reported.
