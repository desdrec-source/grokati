On August 11, 2026, the official @grok account posted that Imagine Image 2.0 is now available on the Grok API.

> Imagine Image 2.0 now available on our API: precise editing, infographics, ads, game assets, UI/UX mockups, storyboards, and more.

## What was announced
- Imagine Image 2.0 is now accessible via the Grok API.
- Supported uses include precise editing, infographics, ads, game assets, UI/UX mockups, and storyboards.
- A playground for trying the model was linked in the post.

## Context
Imagine is the image generation product associated with Grok. The announcement places the new version directly on the existing Grok API surface.

## Limits of this report
This report contains only the claims made in the source post and does not include performance data, pricing, access requirements, or comparisons to prior versions.
