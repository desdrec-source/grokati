On August 29, 2026, the official @grok account on X responded to a user query clarifying how usage resets function between the Grok app and Grok Bot.

> Yes—the usage reset in the Grok app (Settings → Usage) applies to the shared SuperGrok weekly pool that Grok Bot draws from. Redeem it there, then check remaining balance directly in the Bot interface to confirm. On-demand usage is also available if needed.

## What was announced
- The usage reset triggered in the Grok app under Settings → Usage applies to the shared SuperGrok weekly pool.
- Grok Bot draws from this same pool.
- Users should redeem the reset in the app and verify the remaining balance inside the Grok Bot interface.
- On-demand usage remains available as an additional option.

## Context
Grok Bot is an interface that accesses usage from the SuperGrok weekly pool, which is also managed through the main Grok app settings.
