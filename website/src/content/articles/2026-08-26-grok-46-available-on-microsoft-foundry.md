On 26 August 2026, **xAI** published on its news site:

> Today, we’re excited to announce that Grok 4.6 is now available on Microsoft Foundry.

The same page called Grok 4.6 the latest flagship model, “built for long-running agents and ambitious interactive and visual work.”

## What was announced

From [x.ai/news/grok-4-6-microsoft-foundry](https://x.ai/news/grok-4-6-microsoft-foundry):

- Grok 4.6 is available via Microsoft Foundry
- Context window stated as **500k**
- Configurable reasoning efforts: **low**, **medium**, **high**, **xhigh**
- Foundry is described as a place to evaluate Grok 4.6 against other models, run workload-specific tests, deploy managed endpoints, and operate with enterprise security and governance controls

The page also points to the earlier Grok 4.6 model announcement.

## Context

Elon Musk later posted that Grok is in Microsoft Foundry. This article reports the xAI news page, not that X post.

## Limits of this report

No independent review of Foundry pricing, regions, or how Grok 4.6 compares on Foundry benchmarks is included. Those details were not on the news page.
