On 2026-08-13, @cursor_ai posted that Cloud agents now start 3x faster, allowing users to assign ambitious, long-running tasks.

> Cloud agents now start 3x faster so you can hand them ambitious, long-running tasks to execute from start to finish.
> This performance improvement comes from builds: ready-to-use development environments that Cursor prepares continuously in the background, at no additional cost.

## What was announced
- Cloud agents start three times faster.
- The change relies on builds, which are ready-to-use development environments prepared continuously in the background.
- The feature is stated to carry no additional cost.

## Context
Cursor provides an AI code editor with cloud-based agents for executing development tasks.

This report contains only the claims in the source post and does not include performance data, user results, technical details, or comparisons.
