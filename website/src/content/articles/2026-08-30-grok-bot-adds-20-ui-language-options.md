On 2026-08-30, @mattyp posted that Grok Bot supports changing the UI language to any of 20 listed options while noting the bot can already chat in any language.

> Grok Bot can chat in ANY language, but you can also change the language displayed in the UI to: [list of 20 languages including हिन्दी, 简体中文, Polski, Español and others]

## What was announced
- Grok Bot users can select the displayed UI language from the provided list.
- The listed languages are: हिन्दी, 简体中文, 繁體中文, Polski, Español, Português, 日本語, Français, 한국어, Deutsch, Русский, Türkçe, العربية, Italiano, Svenska, English, Українська, Nederlands, Ελληνικά, Afrikaans, עברית.
- A link was shared for changing the setting.

## Context
Grok Bot is the conversational interface associated with Grok on the xAI platform.

## Limits of this report
This report covers only the language list and UI change claim in the source post and does not include details on rollout timing, availability, or additional features.
